# 별빛의 계절 · 웹 테스트 플레이 v14

접속: https://cynic001.github.io/starlit-seasons-web/game/

PC·태블릿 브라우저용 Godot 육성 게임 시제품입니다. 스마트폰에서는 안내 화면을 표시하며 게임 엔진을 내려받지 않습니다. 기기 판별은 브라우저가 제공하는 정보에 기반합니다.

비밀번호 없이 타이틀 → 프롤로그 → 주인공 선택 → 이름 입력 → 월간 일정으로 시작합니다. 12세부터 84개월을 육성하고 19세에 14가지 꿈 중 해당 엔딩을 맞습니다. 진로 달성 조건은 플레이 화면에 표시하지 않습니다.

한 달은 5주이며 학습 / 일·훈련 / 취미·휴식 탭에서 활동을 고릅니다. 영어·수학 수준은 별도로 초급·중급·고급을 설정합니다. 오답에는 힌트와 재도전이 있습니다. 취미 활동은 종류에 따라 스트레스를 줄입니다.

하루 기본 15분입니다. 설정 팝업의 제목을 8번 터치하면 15/30/45/60분·제한 없음을 선택할 수 있습니다. 이미 사용한 시간은 유지합니다. 배경 탭·일시정지는 사용 시간에서 제외하며 미완료 문제 상태를 저장합니다. 서버 관리자 인증은 아직 연결하지 않았습니다.

제목·활동명은 굵게, 설명은 왼쪽 정렬로 표시하며 능력치·골드·스트레스는 별도 줄에 배치했습니다. 팝업은 드래그·휠·스크롤바를 지원하고 드래그 끝에 활동이 잘못 선택되지 않도록 처리했습니다.

일반 캐릭터는 인물3명×성장3단계×의상5종×표정2종=90변형이며 발·신발을 포함한 완성 그림입니다. 현재는 연결된 완성 착장 그림을 사용하며 독립 몸체·의상 레이어 정렬은 추가 작업입니다. 직업 캐릭터42종·직업 배경14종·퀘스트 장면16종을 포함합니다.

브라우저별 저장은 별개이며 기기 간 동기화는 없습니다. 실기기 터치·잠금 복귀·성능은 추가 검증이 필요합니다. 테스트 데이터나 이용자 기록은 이 저장소에 포함하지 않습니다.
