# 별빛의 계절 · 웹 테스트 플레이

설치 없이 브라우저에서 실행하는 Godot 육성 게임 시제품입니다. 이 저장소는 별도 게임 테스트 배포용이며 cynic001.github.io 저장소를 수정하지 않습니다.

시작: 보호자/관리자 비밀번호 최초 설정 → 캐릭터 3종 중 선택 → 이름 입력(1~12자) → 월간 일정.

기본 하루 10분이며 관리자 설정에서 1~120분으로 변경합니다. 배경 탭과 일시정지·관리자 인증 시간은 제외합니다. 미완료 문제와 선택·힌트 상태를 브라우저에 저장하며 다음 접속에 이어갑니다. 같은 브라우저의 중복 게임 탭은 차단합니다.

브라우저별 저장은 별개입니다. 설치판 또는 다른 기기의 기록과 동기화하지 않습니다. 비공개 모드·브라우저 데이터 삭제·기기 시계 변경에 대한 엄격한 통제는 지원하지 않습니다. 관리자 비밀번호 분실 복구는 아직 없습니다.

웹판은 HTTPS 또는 localhost로 실행해야 합니다. 첫 로딩 시 게임 데이터와 엔진을 내려받습니다(현재 약 74MB + 시작 화면 이미지). iPhone SE2 실제 기기 성능·Safari 잠금 복귀는 미검증입니다.

의상 5종, 학습 완료 3회 상인 방문, 14가지 꿈 엔딩(아이돌 가수 포함), 영어·수학 퀘스트, 16개 이벤트 장면을 포함합니다. 활동은 핵심·보조 능력을 함께 올리며, 진로 준비 조건은 핵심45·보조30·관련활동12회입니다. 19세에는 준비된 꿈을 선택하고 다음 여정을 시작합니다. 직업별 배경14종과 세 인물의 전용 의상·동작42종을 적용했고, 선택 시 암전 전환을 제공합니다.

일반 착장은 성장3단계×인물3명×의상5종×표정2종으로90개 표시 변형을 제공합니다. 목·어깨 연결 오류를 막기 위해 현재 화면은 연결된 완성 착장 그림을 사용합니다. 기본 몸체와 의상의 독립 레이어 정렬은 추가 작업입니다. UI는 큰 터치 버튼과 고정된 주요 행동 버튼을 사용합니다. 실제 어린이 사용성, 콘텐츠 분량·균형, 실기기 성능은 추가 검증이 필요합니다.

배포: main 브랜치의 루트를 GitHub Pages에서 제공합니다. 루트는 시작 화면, game/은 게임입니다. 사용자 기록·관리자 비밀번호·QA 데이터는 저장소에 포함하지 않습니다. 한글 글꼴은 Nanum Gothic(SIL OFL), 라이선스는 FONT-LICENSE.txt에 있습니다.

로컬 실행:

```sh
python3 -m http.server 18765 --bind 127.0.0.1
```

http://localhost:18765/에 접속합니다. 게임 원본은 상위 작업 공간의 raising-game/godot/이며 raising-game/build-web.command로 다시 내보냅니다. 이 저장소에는 배포 결과만 보관합니다.


### v10 — 관리자 입력 및 엔딩 전체 보기
관리자 비밀번호는 실제 브라우저 비밀번호 입력란으로 연결합니다. 입력 포커스로 관리자 창이 닫히는 문제를 방지하며 입력값은 인증/닫기 시 제거합니다. 기존 저장과 관리자 비밀번호는 유지합니다.
진로 설명 다음에 직업 캐릭터 전체 모습을 감상하는 화면을 추가했습니다. 설명 복귀와 다른 꿈 선택도 지원합니다.
모델·화면 배치·14개 진로 경로·브라우저 입력 및 인증 검사를 통과했으며, iOS/Android 실제 키보드 동작은 별도 실기기 검증 대상입니다.


### v11 — 입력 및 UI 개선
이름을 실제 브라우저 입력란에 입력합니다. 크기 변경에도 입력값/초점을 유지하고 다음 화면에서 입력란을 제거합니다. 주인공은 큰 카드 한 장을 좌우로 순환하여 선택하며 별도 외형 이름을 표시하지 않습니다. 공통 버튼과 정보창은 선명한 둥근 프레임과 일정한 색·여백으로 정돈했습니다. 키보드로 화면 높이가 줄어드는 경우에는 입력란과 시작 버튼을 우선 표시합니다.
